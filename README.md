# shieldbot
ShieldBot é um assistente de IA semelhante ao ChatGPT, capaz de responder a dúvidas gerais e ajudar na prevenção de golpes digitais. Permite analisar mensagens, imagens e links suspeitos, indicando sinais de risco e orientações de segurança. O projeto prioriza segurança, privacidade e facilidade de uso.
